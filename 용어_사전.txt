case when then
MySQL의 CASE WHEN THEN 문은 조건에 따라 다른 값을 반환하는 조건문입니다.
기본 구조는 CASE WHEN [조건] THEN [결과] ELSE [기본값] END입니다.
기본 문법 구조sql
CASE 
    WHEN 조건1 THEN 결과1
    WHEN 조건2 THEN 결과2
    ELSE 모든 조건이 아닐 때 결과
END
주요 특징
순서대로 실행: 위에서부터 조건을 만족하는지 확인하고 첫 번째 참인 결과만 반환합니다.
ELSE 생략 가능: ELSE를 쓰지 않고 조건을 만족하지 못하면 NULL을 반환합니다.
END 필수: 구문의 마지막은 항상 END로 끝내야 합니다.

coalesce
MySQL과 Oracle에서 COALESCE 함수는 전달된 여러 개의 값(인자) 중에서 NULL이 아닌 첫 번째 값을 반환하는 표준 SQL 함수입니다.
두 데이터베이스 모두 동작 방식이 동일합니다.
공통 특징 및 동작 방식
표준 SQL: ANSI SQL 표준이므로 MySQL과 Oracle뿐만 아니라 대부분의 관계형 데이터베이스에서 똑같이 지원됩니다.
다중 인자 허용: 2개 이상의 인자를 지정할 수 있으며, 왼쪽에서 오른쪽 순서로 확인합니다.
결과 값: 첫 번째로 발견되는 NULL이 아닌 값을 반환하고 종료합니다.
모든 인자가 NULL이면 NULL을 반환합니다.

isnull
MySQL에서 ISNULL()은 전달된 값이 NULL인지 확인하여 1(TRUE) 또는 0(FALSE)를 반환하는 내장 함수입니다.
(값이 NULL이면 1, 아니면 0을 반환)
다만 다른 SQL 문법(예: SQL Server의 ISNULL(expr, 대체값))과 혼동하기 쉬우므로 주의가 필요합니다.
주요 개념 및 차이점
ISNULL(expr) 함수 (MySQL 전용)인자 expr이 NULL인지 검사합니다.
예: SELECT ISNULL(NULL); -> 1 반환
예: SELECT ISNULL('abc'); -> 0 반환
IS NULL 연산자 (표준 SQL)조건절(WHERE)에서 특정 컬럼의 값이 NULL인 행을 필터링할 때 사용하는 표준 연산자입니다.
예: SELECT * FROM users WHERE email IS NULL;IFNULL(expr, 대체값) 함수
타 서버의 ISNULL(A, B)처럼 값이 NULL일 때 다른 값으로 대체하고 싶다면 MySQL에서는 IFNULL() 함수를 사용해야 합니다.
예: SELECT IFNULL(email, 'no-email');

REPLACE
문자열을 바꾸는 함수와 데이터를 넣거나 덮어쓰는 명령어 두 가지 의미로 쓰입니다.
상황에 따라 문자열 치환 함수(REPLACE) 또는 데이터 갱신/삽입 명령어(REPLACE INTO)로 동작합니다.
문자열 바꾸기 함수 (REPLACE)텍스트 안에서 특정 글자를 찾아 다른 글자로 바꿉니다.
기본 문법: REPLACE(문자열, 찾을문자, 바꿀문자)동작 방식: 지정한 문자열에 찾는 글자가 있으면 전부 새로운 글로 바꿉니다.
예시: REPLACE('A-B-C', '-', '') 결과는 'ABC'가 됩니다.
데이터 넣고 덮어쓰기 명령어 (REPLACE INTO)테이블에 데이터를 저장할 때 중복되는 키가 있으면 기존 데이터를 지우고 새 데이터로 바꿉니다.
기본 문법: REPLACE INTO 테이블명 (컬럼) VALUES (값)동작 방식:기본키(Primary Key)나 고유키(Unique Key) 중복이 없으면 새로 넣습니다 (INSERT).
중복이 있으면 기존 데이터를 지우고 새 걸로 바꿉니다 (DELETE 후 INSERT).

sysdate
MySQL의 SYSDATE() 함수는 함수가 실제로 호출되는 시점의 시스템 현재 날짜와 시간을 반환합니다.
주요 특징
함수 호출 기준: 하나의 쿼리 안에서 여러 번 호출되거나,
중간에 SLEEP() 등으로 지연 시간이 발생하면 각기 다른(실행된 순간의) 시간을 반환합니다.
NOW()와의 차이:NOW()는 쿼리가 '시작된' 고정된 시간을 반환하므로 같은 쿼리 내에서는 언제 호출하든 동일한 시간값을 가집니다.
SYSDATE()는 코드가 실행되는 바로 그 순간마다 시간을 새로 읽어옵니다.
