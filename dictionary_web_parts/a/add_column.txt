MySQL에서 테이블에 새 컬럼을 추가하려면 ALTER TABLE 문을 사용합니다. [1, 2] 
가장 기본형은 맨 뒤에 컬럼이 추가되며, 필요에 따라 맨 앞이나 특정 컬럼 뒤에 추가할 수도 있습니다. [1, 3] 
------------------------------
## 1. 기본 컬럼 추가 (맨 뒤에 추가)

ALTER TABLE 테이블명 ADD COLUMN 컬럼명 데이터타입 [제약조건];


* 
* 참고: COLUMN 키워드는 생략해도 무방합니다 (ADD 컬럼명 데이터타입). [2, 4] 
* 

예시: users 테이블에 문자열 형태의 phone 컬럼 추가

ALTER TABLE users ADD COLUMN phone VARCHAR(20) NOT NULL;

------------------------------
## 2. 컬럼 추가 위치 지정하기
MySQL은 새로 추가할 컬럼의 순서를 지정할 수 있는 기능을 제공합니다. [3] 

* 
* 맨 앞에 추가하기 (FIRST)

ALTER TABLE users ADD COLUMN user_id INT FIRST;

* 특정 컬럼 뒤에 추가하기 (AFTER 기존컬럼명)

-- nickname 컬럼을 name 컬럼 바로 뒤에 추가ALTER TABLE users ADD COLUMN nickname VARCHAR(50) AFTER name;

[1, 3, 5] 
* 

------------------------------
## 3. 여러 개의 컬럼 한 번에 추가하기
여러 컬럼을 동시에 추가할 때는 쉼표(,)로 연결하여 작성합니다. [2] 

ALTER TABLE users 
    ADD COLUMN age INT,
    ADD COLUMN address VARCHAR(255) AFTER phone;

------------------------------
혹시 컬럼을 추가하려는 테이블의 기존 구조나, 추가할 컬럼에 기본값(DEFAULT) 설정을 넣어야 하는지 알려주시면 알맞은 SQL 쿼리를 정확히 작성해 드릴 수 있습니다. 어떻게 도와드릴까요?
