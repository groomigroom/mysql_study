nvl

        sql에서 nvl의 의미
        SQL에서 NVL은 데이터의 값이 NULL(빈 값)일 때 다른 값으로 바꿔주는 함수입니다. 
        'Null Value'의 줄임말이며, 
        주로 오라클(Oracle) 데이터베이스에서 사용합니다.
        NVL 함수의 구조와 동작
        기본 형태: NVL(컬럼명, 대체할_값)동작 방식:첫 번째 값(컬럼)이 NULL이 아니면, 
        원래 값을 그대로 보여줍니다.
        첫 번째 값(컬럼)이 NULL이면, 지정한 대체 값을 보여줍니다.
        주요 특징 및 주의점
        데이터 타입 일치: 첫 번째 인자와 두 번째 인자의 데이터 종류(형식)가 같아야 합니다. 
        (예: 숫자에 문자열을 대체하면 오류가 날 수 있습니다.)
        타 데이터베이스 호환: NVL은 오라클 전용 함수입니다. 
        다른 SQL(MySQL의 IFNULL, SQL Server의 ISNULL, 표준 SQL의 COALESCE)에서는 다른 이름의 함수를 씁니다.
