sql에서 sum(급여) over (partition by 부서코드 order by 사원번호)의 의미?
+1

SUM(급여) OVER (PARTITION BY 
부서코드 ORDER BY 사원번호)는 
부서별로 그룹을 나눈 뒤, 사원번호 
순서대로 급여를 누적해서 
더한 값(누적 합계)을 구하는 윈도우 함수 식입니다. 

───

상세 구조별 의미
SUM(급여): 급여의 합계를 구합니다.
PARTITION BY 부서코드: 데이터를 
부서별로 나눕니다 (GROUP BY와 유사한 역할).
ORDER BY 사원번호: 각 부서 안에서 
사원번호 순서로 정렬합니다.
OVER (...): 전체 행을 압축하지 않고, 각 행마다 계산된 누적 합계 결과를 나란히 출력합니다. 

───

동작 방식 (예시)
만약 특정 부서(부서코드: A)에 사원들이 
아래처럼 있고 ORDER BY에 의해 
사원번호순으로 정렬된다면:
1번 사원 (급여 100): 본인까지의 합 = 100
2번 사원 (급여 200): 1번 + 2번 = 300
3번 사원 (급여 150): 1번 + 2번 + 3번 = 450
부서가 바뀌면(PARTITION BY) 누적 합계는 
다시 0부터 시작하여 해당 부서 기준으로 
새로 누적됩니다.
