group by grouping set

        GROUP BY GROUPING SETS (col1)은 일반적인 GROUP BY col1과 완전히 동일한 결과를 반환합니다. 단 하나의 컬럼만으로 구성된 그룹 집합을 정의했기 때문입니다.
        ## 1. 동작 방식
        
        * GROUPING SETS 내부에 정의된 단 하나의 항목인 col1을 기준으로만 데이터를 그룹화합니다.
        * 추가적인 합계(Grand Total)나 소계(Subtotal) 행을 생성하지 않습니다.
        
        ## 2. 실제 활용 목적
        결과물은 일반 GROUP BY와 같지만, 실무에서는 다음과 같은 이유로 작성하곤 합니다.
        
        * 동적 쿼리 작성: 조건에 따라 그룹화 대상을 추가/삭제하기 편하도록 템플릿 형태로 열어둘 때 사용합니다.
        * 확장성 고려: 나중에 GROUPING SETS (col1, col2, ())처럼 소계나 전체 합계를 쉽게 추가할 수 있도록 구조를 미리 잡아둘 때 씁니다.
        
        이 문법을 활용해서 특정 소계(예: 전체 합계 행 추가)를 함께 구하고 싶으신 건가요? 원하시는 최종 결과 테이블의 형태를 말씀해 주시면 알맞은 집계 방식을 제안해 드리겠습니다.
        
        
        아닙니다. SQL 표준(ANSI SQL) 문법입니다.

        sql에서 group by grouping sets((a, b), (a), (b), ())

        GROUP BY GROUPING SETS ((a, b), (a), (b), ())은
        하나의 쿼리 안에서 지정한 4가지 서로 다른 기준(그룹화 집합)으로
        각각 집계한 결과를 하나로 합쳐서(UNION ALL 한 것처럼) 
        보여주는 문법입니다.
        개별 그룹화 세트의 의미(a, b): 열 a와 b를 동시에 기준으로
        삼아 그룹화합니다 (GROUP BY a, b와 동일).
        (a): 열 a만 기준으로 삼아 그룹화합니다 (GROUP BY a와 동일).
        (b): 열 b만 기준으로 삼아 그룹화합니다 (GROUP BY b와 동일)
        (): 열을 전혀 그룹화하지 않고 전체 데이터를 대상으로 집계합니다 
        (전체 총합, GROUP BY 없는 집계와 동일).
        특징 및 활용
        결과 합치기: 위 4개의 독립된 GROUP BY 결과를 하나의 결과 집합으로 반환합니다.
        소계와 총합: a별 소계, b별 소계, (a,b) 조합별 상세 소계, 
        그리고 전체 총합을 한 번에 조회할 때 유용합니다.
        NULL 값 발생: 특정 그룹화 기준에 포함되지 않는 열의 값은 결과 
        밴드에서 NULL로 채워져 출력됩니다.
