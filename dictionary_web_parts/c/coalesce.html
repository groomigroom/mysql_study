        coalesce
        오라클의 COALESCE 함수는 전달된 여러 개의 값 중에서 NULL이 아닌 첫 번째 값을 반환하는 함수입니다.
        모든 값이 NULL인 경우에는 NULL을 반환합니다.
        주요 특징
        다중 인자 처리: 2개 이상의 많은 인수를 지정할 수 있습니다. 
        앞에서부터 차례대로 검사해 NULL이 아닌 값이 나오면 뒤의 값은 보지 않고 바로 반환합니다.
        ANSI 표준: 오라클뿐만 아니라 다른 데이터베이스(SQL Server, PostgreSQL 등)에서도 공통으로 사용할 수 있는 표준 함수입니다.
        NVL과의 차이: NVL은 인자 2개만 받아 첫째가 NULL일 때 둘째를 반환하지만, 
        COALESCE는 여러 개를 나열할 수 있어 확장된 형태입니다.

        주요 활용법
        1. NULL 값을 다른 값으로 치환하기컬럼의 값이 NULL일 때 대체할 기본값을 지정할 수 있습니다.
        예시: SELECT COALESCE(phone_number, '번호 없음') FROM users;
        (phone_number가 NULL이면 '번호 없음' 출력)
        2. 여러 컬럼 중 비어 있지 않은 첫 번째 값 찾기여러 연락처나 이름 컬럼 중 
        입력된 우선순위에 따라 값을 선택할 때 유용합니다.
        예시: SELECT COALESCE(nickname, first_name, '손님') FROM users;
        (nickname이 있으면 출력, 없으면 first_name 확인, 둘 다 없으면 '손님' 출력)
