MySQL Workbench에서 자동 로그인을 해제하려면 저장된 비밀번호(Vault)를 삭제해야 합니다.
다음 순서대로 진행하시면 접속할 때마다 항상 비밀번호를 물어보게 됩니다.
## 자동 로그인 해제 방법

   1. MySQL Workbench 홈 화면에서 자동 로그인을 해제할 연결(Connection) 카드를 찾습니다.
   2. 해당 카드 위에서 마우스 우클릭을 한 뒤, 메뉴에서 [Edit Connection...]을 클릭합니다.
   3. 설정 창이 뜨면 중간에 있는 Password: 항목을 확인합니다.
   4. 항목 오른쪽에 있는 [Clear] 버튼을 클릭합니다. (이 버튼을 누르면 저장되어 있던 비밀번호가 삭제됩니다)
   5. 오른쪽 아래에 있는 [Close] 버튼을 눌러 창을 닫습니다.

이제 해당 카드를 더블클릭하여 접속하면, 자동으로 로그인되지 않고 비밀번호 입력 창이 새로 뜨게 됩니다.
혹시 이 방법으로도 비밀번호 창이 뜨지 않거나, 특정 사용자 계정 자체를 삭제하고 새로 설정하고 싶으신가요? 상황을 말씀해 주시면 추가로 안내해 드리겠습니다.
