create table TBL
(ID integer);

insert into TBL
values
(100),
(100),
(200),
(200),
(200),
(999),
(999);

select ID from TBL
group by ID
having count(*) = 2
order by(case when ID = 999 then 0 else ID end);

제시해주신 MySQL 쿼리는 데이터 그룹화 ➡️ 조건 필터링 ➡️ 정렬 변환 순서로 작동합니다.이 쿼리의 작동 원리를 실행 순서에 따라 단계별로 쉽게 설명해 드리겠습니다.1. 데이터 집합 생성 (FROM)우선 TBL 테이블에 아래와 같이 7개의 행(Row)이 들어있는 상태에서 시작합니다.데이터: 100, 100, 200, 200, 200, 999, 9992. 같은 ID끼리 묶기 (GROUP BY)GROUP BY ID를 만나면 데이터베이스는 동일한 ID를 가진 행들을 하나의 그룹으로 묶습니다.100 그룹: 행 2개200 그룹: 행 3개999 그룹: 행 2개3. 개수가 2개인 그룹만 남기기 (HAVING)HAVING은 그룹화된 결과에 조건을 걸 때 사용합니다. count(*)는 각 그룹에 속한 행의 개수를 의미합니다. 이 개수가 정확히 2개(= 2)인 그룹만 통과시킵니다.100 그룹: 2개 ➡️ 합격200 그룹: 3개 ➡️ 탈락999 그룹: 2개 ➡️ 합격이 시점에서 결과 데이터는 100과 999 두 가지만 남게 됩니다.4. 특별한 기준으로 정렬하기 (ORDER BY CASE)ORDER BY 절에 CASE WHEN 조건문이 사용되어 정렬 기준 값이 실시간으로 변환됩니다. 이 조건은 **"ID가 999라면 0으로 취급하고, 그 외에는 원래 ID 값으로 취급해서 정렬하라"**는 뜻입니다.실제 정렬을 위해 계산되는 가상의 값은 다음과 같습니다.ID가 999인 그룹: 조건에 의해 0으로 변환됨ID가 100인 그룹: 조건에 의해 원래 값인 100으로 유지됨변환된 값(0과 100)을 기준으로 오름차순(기본값) 정렬을 수행하므로, 0으로 취급된 999가 100보다 앞으로 오게 됩니다.
