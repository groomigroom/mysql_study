sql에서 grouping sets((DNAME, JOB), DNAME)의 의미
GROUP BY GROUPING SETS ((DNAME, JOB), DNAME)은 
전체 데이터를 지정한 개별 집합별로 각각 그룹화하여 DNAME과 JOB을 
모두 묶은 결과와 DNAME만 묶은 결과를 하나로 합쳐서(UNION) 보여줍니다.
동작 방식 및 의미
(DNAME, JOB) 그룹: 부서(DNAME)와 직무(JOB)를 동시에 기준으로 삼아 
데이터를 집계합니다.
DNAME 그룹: 부서(DNAME)별로만 데이터를 모아서 집계합니다 
(부서별 소계 역할).
이 두 가지 집계 결과를 UNION ALL로 합친 것과 정확히 같은 결과가 나옵니다.
비교 예시
결과적으로 아래 두 쿼리는 같은 역할을 합니다.
sql-- 
GROUPING SETS 사용
SELECT DNAME, JOB, COUNT(*) 
FROM EMP 
GROUP BY GROUPING SETS ((DNAME, JOB), DNAME);
코드를 사용할 때는 주의가 필요합니다.
sql-- 
UNION ALL 사용 (동일한 의미)
SELECT DNAME, JOB, COUNT(*) FROM EMP GROUP BY DNAME, JOB
UNION ALL
SELECT DNAME, NULL AS JOB, COUNT(*) FROM EMP GROUP BY DNAME;
