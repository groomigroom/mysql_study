MySQL에서 사용자 계정을 삭제하려면 DROP USER 명령어를 사용해야 합니다. 계정을 생성할 때 사용했던 '사용자명'과 '호스트(@ 뒤의 값)'를 정확히 지정해야 합니다. [1] 
## 기본 삭제 명령어

DROP USER 'developer'@'%';

## 주의할 점 및 추가 팁

* 호스트 일치: 생성할 때 기재한 호스트와 일치해야 합니다. 만약 로컬용 계정이었다면 DROP USER 'developer'@'localhost';와 같이 적어야 합니다.
* 존재하지 않는 계정 오류 방지: 만약 계정이 없을 때 발생할 수 있는 에러를 방지하려면 IF EXISTS를 추가하는 것이 안전합니다.

DROP USER IF EXISTS 'developer'@'%';

* 권한 즉시 반영: 계정을 삭제한 후 변경 사항을 서버에 즉시 적용하려면 다음 명령어를 실행합니다.

FLUSH PRIVILEGES;
